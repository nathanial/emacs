# Emacs Folder Structure

## Overview
This document summarizes the major directories and files in the Emacs source tree rooted at the repository top level. Paths are listed relative to the repository root (e.g., `src/` refers to `/Users/Shared/Projects/emacs/src`).

## Core Source Code
- `src/` – C sources for the Emacs executable, low-level runtime, garbage collector, display backends, and platform glue code.
- `lisp/` – Emacs Lisp standard library; each subdirectory groups related functionality (editing modes, packages, UI components, etc.).
- `leim/` – "Library of Emacs Input Methods" containing input method definitions and data files used at runtime.
- `lib/` – Gnulib import providing portable replacements for standard C library functionality required by Emacs.
- `lib-src/` – Auxiliary programs written in C (e.g., `etags`, `emacsclient`, `movemail`) that are built alongside the main binary.
- `modules/` – Example and test dynamic modules demonstrating the Emacs module API.

## Platform-Specific Support
- `nextstep/` – Files for the macOS (Cocoa) GUI port. After `make install`, the self-contained macOS bundle lives at `nextstep/Emacs.app`.

## Build System and Tooling
- `autogen.sh`, `configure.ac`, `GNUmakefile`, `Makefile.in` – Entry points for generating and running the Autotools-based build system.
- `build-aux/` – Helper scripts shared across the build (install wrappers, maintainer scripts, etc.).
- `m4/` – Autoconf macro definitions consumed during configuration.
- `admin/` – Maintainer utilities, CI helpers, code generation scripts, and data (e.g., Unicode tables, NEWS tooling).
- `exec/` – Sources and build scripts for the portable dumper and related executable-loading infrastructure.
- `autom4te.cache/` – Autotools cache directory generated by `autogen.sh`/`configure` (safe to remove to force regeneration).

## Documentation and Assets
- `doc/` – All official documentation. Key subdirectories:
  - `doc/emacs/` – User manual sources.
  - `doc/misc/` – Manuals for bundled packages (Org, TRAMP, etc.).
  - `doc/lispintro/` and `doc/lispref/` – Emacs Lisp introduction and reference manuals.
  - `doc/man/` – Man pages such as `emacs.1`.
- `etc/` – Runtime data: splash images, tutorial files, locale data, sample init files, and other assets installed with Emacs.
- `info/` – Generated GNU Info manuals (populated by the build; not tracked in git by default).

## Testing and Quality Assurance
- `test/` – Automated test suites (ERT-based Lisp tests, C unit tests, integration harnesses).
- `admin/grammars/`, `admin/unidata/`, and related subdirectories feed generated sources used by tests and runtime validation.

## Build Outputs and Installed Artifacts
- `nextstep/Emacs.app/` – macOS GUI bundle produced by `make install` when building with `--with-ns`.
- `info/` and `nextstep/Emacs.app/Contents/Resources/` – Populated during the build; remove or clean via `make distclean` or `git clean` to revert to a pristine tree.
- `src/temacs`, `src/bootstrap-emacs`, and other intermediates appear during compilation and live under their respective directories until cleaned.

## Supporting Files in the Root
- `INSTALL`, `INSTALL.REPO`, `README`, `CONTRIBUTE`, `COPYING` – High-level project guidance, licensing, and contribution notes.
- `ChangeLog.*` and `doc/ChangeLog` – Historical change logs retained for archival reference.
- `make-dist` and related scripts – Release engineering helpers for packing Emacs distribution tarballs.

## Clean-Up Tips
- Use `make clean` or `make distclean` to remove most generated objects when switching configurations.
- `git clean -fdx` (with caution) restores the repository to a pristine state by removing untracked build outputs like `nextstep/Emacs.app/` and `autom4te.cache/`.

This overview focuses on the directories commonly touched when building or hacking on Emacs. Consult `INSTALL.REPO` for detailed build instructions and `CONTRIBUTE` for contribution workflows.
